01 / Explore

點樣使用港啡

探索

搵啱你嘅咖啡店

用中英文店名、地址或地區搜尋。可以再按香港 18 區同「有 Wi-Fi」收窄結果。Wi-Fi 篩選只包括來源已標記嘅店舖。

店舖詳情

睇資料，再出發

打開店舖卡片睇地址、營業時間同聯絡資料。地圖、導航、電話同網站會交由手機相應嘅 App 開啟。

收藏與足跡

留低想去同去過嘅店

用書籤加入收藏，撳「標記已到訪」加入足跡。寫好私人筆記後撳「儲存筆記」，重開 App 亦可以睇返。

私人新增

加一間自己發現嘅店

喺探索頁撳右上角「＋」，填寫店名、地區同地址。新增店舖同筆記只儲存喺你部裝置。

02 / Get started

安裝與開發

安裝正式版 APK

下載 v1.0.0 APK

已簽署安裝檔 · 約 10 MB · Android 8.0 或以上。下載時請登入有權限存取此 GitHub 專案嘅帳戶。

  1. 用 Android 手機開啟下載連結，儲存 app-release.apk。
  2. 喺「檔案」App 開啟 APK。如果系統詢問，為開啟 APK 嘅 App 選「允許來自此來源」。
  3. 撳「安裝」，完成後打開「港啡 HK Coffee」。

Android 安裝指引 ↗

喺 Android Studio 開專案

  1. 用 Get from VCS clone GitHub 專案，或者開啟包含 settings.gradle.kts 嘅專案根目錄。
  2. 用 JDK 17，安裝 Android SDK Platform 35，等 Gradle Sync 完成。
  3. 揀 Android 8.0 或以上嘅真機或模擬器，再撳 Run。

GitHub 專案 ↗

編譯測試版

喺專案根目錄執行以下指令。Windows 用 gradlew.bat 代替 bash gradlew。

bash gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug

編譯完成後，APK 喺 app/build/outputs/apk/debug/app-debug.apk。首次 Gradle Sync 需要網絡下載依賴。

03 / Device testing

用 Android 真機測試

  1. 喺手機開啟「開發人員選項」入面嘅 USB 偵錯。
  2. 用可傳輸資料嘅 USB 線接駁電腦。保持手機解鎖，按手機提示允許呢部電腦偵錯。
  3. 喺 Android Studio 頂部裝置清單揀你部手機，揀 app 執行設定，再撳 Run ▶。
  4. 打開 App 試搜尋、篩選同收藏。關閉再重開，確認收藏同筆記仍然喺度。

Android Studio 真機測試指引 ↗

小米／Redmi 安裝提示

如果 Android Studio 顯示 INSTALL_FAILED_USER_RESTRICTED 同 Installation via USB is disabled，要喺手機開啟「透過 USB 安裝」。睇小米設定步驟。

04 / Troubleshooting

常見問題

小米／Redmi 顯示 USB 安裝被停用
  1. 喺手機去 設定 → 更多設定 → 開發人員選項，開啟 透過 USB 安裝（Install via USB）。USB 偵錯同 USB 安裝係兩個獨立開關。
  2. 如果搵唔到，可以試 設定 → 應用程式 → 權限 → 透過 USB 安裝。入口會隨 MIUI 版本而有分別。
  3. 保持手機解鎖，返 Android Studio 撳 Run 或 Retry。如果手機彈出安裝確認，撳允許。

Redmi Note 9 Pro 設定指引 ↗ MIUI 13 手冊 ↗

Android Studio 裝置清單搵唔到手機

確認手機已解鎖、USB 偵錯已開啟，並已批准電腦偵錯。試重新插線，或者換一條可以傳輸資料嘅 USB 線。

Android Studio 裝置連線排查 ↗

裝過 debug 版，正式版提示簽署不符

呢個正式版同之前嘅 debug 版用咗唔同簽署。確認可以清除舊版嘅收藏、足跡同私人筆記後，再解除安裝 debug 版並安裝正式版。

Gradle Sync 提示缺少 SDK 或 Java

喺 SDK Manager 安裝 Android SDK Platform 35。喺 Android Studio 設定嘅 Gradle JDK 選 JDK 17 或相容嘅內置 JDK，再重新 Sync。

更新咖啡店資料失敗

公開 Overpass 服務可能繁忙或逾時。等至少一分鐘再試，或者匯入有效嘅 Overpass JSON。更新失敗時仍可使用原有目錄。

05 / Data & privacy

資料、更新與私隱

隨附目錄以香港 18 區邊界篩選 OpenStreetMap 咖啡店紀錄。快照時間係香港時間 2026 年 10 月 26 日 05:21。社群資料可能有遺漏、重複或已過時嘅營業資訊。

更新或匯入店舖目錄

喺「資料」頁撳「從 OpenStreetMap 更新」，App 會發出一次香港範圍查詢。亦可以喺 Overpass Turbo 執行下列查詢，匯出原始 JSON，然後喺 App 撳「匯入 Overpass JSON 目錄」。檔案須小於 12 MB，並含有效香港咖啡店座標。

[out:json][timeout:90];
area["ISO3166-1"="HK"]["boundary"="administrative"]->.hk;
nwr["amenity"="cafe"](area.hk);
out center tags;

私人紀錄只儲存喺本機。 匯入或更新會更換公開店舖目錄，私人新增同筆記會保留。解除安裝或清除 App 資料會刪除本機私人紀錄。

店舖目錄及行政邊界為 © OpenStreetMap contributors，按 ODbL 1.0 提供。
